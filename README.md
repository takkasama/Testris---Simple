# Tetris---Simple


Entorno grafico : 

Para el desarrollo de la interfaz grafica del juego se uso la libreria grafica de Raylib (https://github.com/raysan5/raylib/releases)


Instrucciones de Instalacion : 

- - Requerimentos  - -

a . Tener un sistema operativo de Linux (sin requerimentos especificos para el ordenador).
b . Contar con IDE de zijai (https://zinjai.sourceforge.net/index.php?page=descargas.php&os=lnx)

- -Intrucciones de ejecucion - -

1 . Clonar el repositorio : https://github.com/takkasama/Testris---Simple.git o Acceder a la opcion de code y descargar el .zip del code
2 . Una vez descargado el Programa Ejecutar el Archivo (Tetris-Simple.zpr)
3 . Si se tiene el IDE de zinjai , abrira dicho ide , en el cual se procedera a usar la opcion de copilacion.
